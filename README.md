# Site Adrenalina Rio Kart

One-page de conversao do Adrenalina Rio Kart (kart indoor, Shopping Jardim Guadalupe, RJ).
Site estatico servido por nginx. Deploy via EasyPanel (build do Dockerfile).

- Fonte editavel: repositorio local `adrenalinakart/site/src/page.html` (placeholders de logo/fontes/hero)
- Este repo recebe o `index.html` final com tudo embutido.
